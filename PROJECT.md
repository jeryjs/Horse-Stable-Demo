### Objective
Develop a small working application for managing horses and their daily activities in a horse stable.

You may use **any programming language, framework, database, development platform, and AI tools**.

The objective is not to build a complete commercial system within 90 minutes. We want to evaluate your **technical ability, logical thinking, creativity, UI design, and effective use of AI tools.**

---

### 1. Horse Profile
Create a screen to **Add, View and Edit Horses**.

Minimum information:
* Horse ID – Auto Generated
* Horse Name
* Breed
* Gender
* Age / Date of Birth
* Owner Name
* Stall Number
* Current Status
* Horse Photo – Optional

**Suggested Status:**  
**Active / Training / Rest / Medical Attention / Out**

---

### 2. Horse Activity & History
Allow users to add activities against each horse.

Minimum fields:
* Date
* Horse
* Activity Type
* Notes
* Staff / Trainer

**Example Activity Types:**  
**Training / Exercise / Feeding / Grooming / Veterinary / Medication / Farrier / Rest / Other**

When viewing a Horse Profile, show its previous activities as a **History or Timeline**.

**Example:**  
**THUNDER**  
07 Oct – Training – 45-minute exercise  
06 Oct – Grooming  
05 Oct – Veterinary Check  
04 Oct – Exercise  

---

### 3. Dashboard
Create a simple dashboard showing:
* Total Horses
* Active Horses
* Horses Under Training
* Horses Requiring Attention
* Today's Activities

You may add charts or other useful information if time permits.

---

### 4. Search / Filter
Provide at least a basic facility to:
* Search Horse by Name or ID
* Filter Horses by Status

---

### 5. AI / Creative Feature
Add **one useful AI or smart feature of your choice**.  
You are free to decide what would add value to the stable.

**Examples:**
* AI summary of a horse's recent history
* Recommended next action
* Automatic activity classification
* Natural-language horse search
* Smart alerts
* AI assistant
* Health/activity summary

**Creativity will be considered in the evaluation.**
